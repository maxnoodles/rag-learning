# 基础 RAG 封板记录

封板日期：2026-10-15。范围：`01-simple_rag` 当前工作区实现，包含 MMR 前置压缩及主流程拆分；不能仅用此前的 `93f17d2` 提交代表本次基线。本记录标记功能封板，不代表已创建 Git 发布标签或提交。

## 已封板能力

- TXT / Markdown 解析、按问答组递归切分、token 预算与原文范围追踪。
- 本地 Google EmbeddingGemma 2、FAISS 向量索引、SQLite 元数据及磁盘快照校验。
- 原问题与 Codex 抽象问题两轮 FAISS + BM25 检索、加权 RRF 融合。
- 按 chunk ID 合并，保留最强轮次的召回分数与全部命中轮次。
- MMR 压缩后使用本地 BGE Cross-Encoder 按原问题重排。
- 上下文去重、同组补全、证据预算、Codex 带引用回答及可选 JSON 过程记录。

默认流程（数量均为上限）：

```text
每轮 FAISS / BM25 各 fetch_k=10 → RRF top_k=4
原问题与抽象问题两轮合并去重 → 最多 8
MMR（lambda=0.7）→ mmr_k=4
Cross-Encoder → top_n=2
上下文合并与预算 → 带引用回答
```
